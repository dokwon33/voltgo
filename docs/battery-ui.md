# 배터리 표시

배터리 모양은 `web/battery.css`의 얇은 케이스·잔량 채움으로 구성한다.
전체 두께는 20px(내부 바 12px)이며, 숫자와 충전 상태는 바 위 한 줄, 도달 시간은 바 아래 한 줄에 표시한다.
두꺼운 그림자와 분할선은 사용하지 않고, 작은 단자와 옅은 테두리로 배터리 형태를 남긴다.
실제 게이지 폭은 `session.charging.soc_pct`에 비례한다. 이미지를 교체하지 않아도
잔량과 색상이 함께 변한다. 상태 결정은 `web/app.js`의 `renderCar()`에서 한다.

| 잔량 | 색상 | 표시 |
|---|---|---|
| 0~20% | 코랄 | 잔량 부족 |
| 20% 초과~40% | 앰버 | 잔량 보통 |
| 40% 초과~100% | 민트 | 잔량 여유, 100%는 가득 참 |
| 누락·숫자 아님·범위 밖 | 회색 | 잔량 미확인 |

위 구간은 화면용 기본값이며 차량 제조사의 경고 기준이나 추천 계산을 바꾸지 않는다.
소수 잔량은 표시할 때 소수 첫째 자리까지 보여준다.

충전 상태는 잔량과 독립적이다. `charging === true`일 때만 번개·`충전 중`·빛 움직임을
표시한다. `false`는 일시정지 모양·`충전 안 함`, 누락 또는 `null`은 `충전 상태 미확인`이다.
낮은 잔량으로 충전 중이면 코랄 게이지와 초록 충전 배지를 함께 표시한다.
색상 외에 문구와 접근성 이름으로 상태를 전달하며, 모션 줄이기 설정에서는 빛 움직임을 끈다.

게이지에는 계산용 `display_charging.target_soc_pct` 위치의 옅은 점선을 표시한다.
목표가 없으면 점선을 숨기고 목표 충전량 입력을 안내한다. 차량 설정과 사용자 요청이
다를 때 웹 브리지는 공통 `_apply_target_soc()` 보정 규칙으로 계산용 값을 전달한다.
충전 중에는 `80%까지 약 40분 · 11:28 예정`처럼 잔여시간과 완료 시각을
표시한다. `home_budget.finish_at`과 서버 `now`의 차이를 우선 사용하며, 없으면
`reported_remaining_sec`를 사용한다. 완료 시각만 없으면 데이터 측정 시각(`observed_at`)에 잔여시간을
더해 계산한다. 측정 시각도 없으면 임의의 완료 시각을 만들지 않는다. 서버 응답 시점의 추정값이며, 새로운 응답을 받으면 갱신한다.
시간 정보가 없으면 `시간 확인 중`, 목표 잔량 이상이면 `목표에 도달했어요`로
표시한다. 충전 중이 아니면 이 시간 안내를 숨긴다.

차량 상세는 자동차 아이콘의 대화상자에서 확인한다. 충전 완료 예정 시각은 충전 중이고
`home_budget.finish_at`이 있을 때만 표시한다. 복귀 예정 시각은 이 창에 표시하지 않는다.

고운돋움(한글), Nunito(숫자·로고)는 `web/fonts`에 WOFF2로 포함해 외부 폰트 요청 없이
표시한다. Google Fonts에서 받은 글꼴이며, 각 OFL 라이선스를 같은 폴더에 보관한다.

홈에서는 잔량 여유·보통 설명을 생략한다. 잔량 부족·필요한 미확인 안내만 짧게 남긴다.
차량 상세의 측정 시각·조회 시각·계산 근거는 ‘충전 정보 상세’를 펼치면 볼 수 있다.
