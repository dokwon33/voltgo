# VoltGo 실행결과 기록양식

- 실행자:
- 실행일시와 시간대:
- 실행 명령:
- 실제 코드 SHA와 브랜치:
- 작업 트리 변경 유무:
- Python과 Node 버전:
- 실행 모드: 자동 고정 대역 / 실제 모델과 Mock API / 실계정 API
- 결과 JSON과 로그 위치:

| TC 또는 M | 실제 입력과 조건 | 기대 결과 | 실제 결과와 로그 | PASS 또는 FAIL 또는 미실행 | 후속 조치와 담당 |
|---|---|---|---|---|---|
| | | | | | |

Python 성공/실패/오류/skip 수와 Node pass/fail 수를 별도로 기록한다. suite와 all의 수치를 합산하지 않는다. API 키·쿠키·토큰·실차 식별자를 기록하지 않는다. 시각·판정·오류 코드와 필요한 도구 로그만 첨부한다.
