# 프론트 반영 결과 · 팀 요청사항

2026-09-11 기준. `main`의 `a2d9ac2`(E PR #4)를 기반으로
`feat/web-experience`에 현재 웹 화면과 웹 서버·테스트를 모았다.
유저 격리 구현은 A(김보석) 담당이며, 이 브랜치는 기존 사용자 ID 방식을 유지한다.

## 반영한 화면

- 홈 ‘지금 뭐 할까요?’ 오른쪽과 대화 상단에 ‘대화 기록’. 기존 ‘이전 대화 이어보기’ 제거.
- 최근 20개 대화, 대화당 최근 100개 메시지를 사용자별로 이 브라우저에 보관.
  날짜·첫 질문으로 목록을 표시하고 새 대화를 시작할 수 있다.
  같은 서버 프로세스의 대화는 이어서 대화 가능. 서버 재시작·연결 실패 시에는
  보관된 내용 조회만 허용하고 ‘새 대화로 추천받기’를 표시한다.
- ‘조건 바꾸기’: 활동, 목표 충전량, 시간 제한, 체류시간, 출발 충전소.
  실제 적용은 기존 에이전트 도구를 사용하며, 화면은 반환된 조건만 표시한다.
  입력하지 않은 항목은 유지한다. 시간 제한은 1~1440분, 체류시간은 5~60분 UI 범위다.
- 충전소 후보의 이름·주소를 선택 카드로 표시. 직전 후보 ID를 서버에서 검사한 뒤 전달.
- ‘내 취향’: 기존 선호 조회, 변경·저장 요청, 삭제.
  저장 승인에는 실제 도구 인자(활동·체류시간), 남은 승인시간을 표시한다.
- 승인 요청 ID 유지·재전송. 웹 브리지에서 동일 요청의 중복 실행 방지, 잘못된/지난 ID 거부.
  E의 저장만 승인하는 정책을 유지한다. 계획 선택은 최신 상태로 재검증 후 바로 확정한다.
- 추천 카드의 ID·버전·생성시각을 함께 전달. 조건 변경·충전 갱신·5분 경과·보관 대화의
  과거 카드는 비활성화. 클릭 시 웹 서버에서도 같은 조건을 다시 검사한다.
- 추천 카드에 모바일에서도 여는 왕복 시간·거리/경로 설명.
- 확정한 목적지 이름과 큰 초록색 지도 버튼. 목적지 유지·다른 후보 선택·새 조건 검색을
  선택할 수 있다. 이전 목적지와 현재 목적지를 구분하고 상단 지도는 현재 목적지를 우선한다.
- `confirm_plan`에서 A → B → A 재선택도 현재 시각으로 재검증하고 현재 목적지를 바꾼다.
  A 브랜치의 `confirmed_by_plan` 이름 변경을 합칠 때 이 조건도 유지한다.
- 화면의 Mock·영업 미확인 표시는 제거했다. API의 원본 출처 필드와 잔여시간 추정 안내는 유지한다.
- 차량 상세의 강제 새로고침, 측정·조회 시각, 정보 출처와 계산 근거.
  갱신 후 예전 추천을 무효화하고 다시 추천받도록 안내한다.
- 얇은 배터리 게이지, 충전 여부와 잔량 색상, 목표 점선, 도달 예상 시각·남은 시간 유지.
  차량 목표와 요청 목표가 다르면 계산에 쓴 목표로 표시한다.
  목표 결측 시 임의의 80% 대신 미확인 안내를 표시한다.
- 대화가 길어져도 상단 도구와 입력창은 유지하고 메시지만 스크롤한다.
- 지도 SDK·마커·가는 길/오는 길 선택 UI 유지. 실제 좌표만 사용한다.
  웹 브리지가 Session의 출발지·장소 좌표를 `map_data`로 전달한다.

## 아직 외부 연결이 필요한 범위

실제 지도 타일에는 브라우저용 TMAP 키가 필요하다. 실제 도보 선에는 D의 경로 좌표가
필요하다. 지금은 키 미설정·경로 미제공 상태를 정확히 안내한다. 임의 경로선을 만들지 않는다.
남은 충전 시간의 직접 입력은 핵심 도구에 저장 경로가 없어 상태 안내와 재조회까지 연결했다.
서버 재시작을 넘는 이어서 대화하기와 기기 간 기록 동기화는 서버 저장 기능이 필요하다.

## 확인 방법

```bash
# 프로젝트 루트. dotenv 포함 프로젝트 의존성은 .venv에 설치되어 있어야 한다.
.venv/bin/python scripts/web.py --fixed
.venv/bin/python -m pytest -q
# @playwright/test 및 Chromium이 설치된 환경에서
node web/tests/features.cjs
node web/tests/map.cjs
node web/tests/navigation.cjs
node web/tests/home-character.cjs
node web/tests/destination.cjs
```

프론트 브라우저 검증은 테스트 응답/지도 SDK를 사용한다. 실계정 LLM·차량·TMAP API는
호출하지 않았다. 현재 Python 전체 테스트 150개 통과. 기존 Pydantic 직렬화 경고는 남아 있다.

서버가 이미 켜져 있었다면 Python 프로세스를 재시작해야 새 `/api/refresh`와 응답 필드가
반영된다. 정적 파일은 새로고침으로 반영된다.

## 홈·뒤로가기 수정

- VoltGo 로고는 키보드로도 누를 수 있는 홈 버튼이다. 일반 홈 이동은 thread와 메시지를 유지한다.
- 홈에서 바로 연 지도는 뒤로가기로 홈에 복귀한다. 대화에서 연 지도는 대화로 복귀한다.
- 지도 안의 장소 전환은 같은 지도 방문 기록을 갱신한다.
- 차량·설정·기록·실행 정보 창은 배경 화면과 지도 선택을 함께 보관한다.
  닫기/Esc/브라우저 뒤로가기가 같은 복귀 동작을 쓰며, 앞으로가기도 배경부터 복원한다.
- 설정 제출 시 팝업 방문 기록을 실제로 되돌린 다음 질문을 보낸다. 중복 대화 기록을 추가하지 않는다.
- 새 대화와 기록 복원은 방문 기록의 범위를 새로 구분한다. 앱 뒤로가기에서 이전 대화의 지도나 외부 페이지로 빠지지 않는다.
- 홈으로 이동한 뒤 도착한 응답은 홈을 유지한다. 저장 승인 창을 뒤로 닫아도 승인·거절은 실행하지 않으며,
  ‘취향 저장 요청 확인’에서 같은 요청을 다시 열 수 있다.
